# 🛡️ Apertus Sentinel — Automated AI Security & OWASP Code Auditor

A lightweight, automated security auditing tool leveraging Switzerland's sovereign LLM (`Apertus-v1.5-8B`) via the CSCS Inference API. **Apertus Sentinel** performs static code analysis across Python codebases, detects OWASP Top 10 vulnerabilities and AI Context Infiltration vectors, dynamically scores repository health, and interactively applies secure code patches.

---

## 🚀 Key Features

- **Multi-File Batch Auditing:** Automatically scans directories of Python scripts for vulnerabilities.
- **OWASP Top 10 & AI Risk Detection:** Identifies flaws ranging from Command Injection and SQL Injection to Unvalidated Financial Transfers and Indirect Prompt Injection (Context Infiltration).
- **Dynamic Security Scoring & Badges:** Calculates a real-time security score and embeds dynamic shield badges into the audit report.
- **Interactive Auto-Fixer (CLI):** Prompts the user to automatically generate and export patched, secure code files to a dedicated `patched_files/` output directory.
- **Markdown Security Reporting:** Produces structured audit reports rendered natively in Markdown format.

## 💻 How to Run

### 1. Prerequisites
Install the required dependency:
```bash
pip install openai
```

### 2. Configure CSCS API Key
In `auditor.py`, verify your CSCS Inference API key line:
```python
client = OpenAI(
    base_url="[https://api.inference.cscs.ch/v1](https://api.inference.cscs.ch/v1)",
    api_key="YOUR_CSCS_API_KEY"
)
```

### 3. Execute Security Audit
Run the auditor script using Python:
```bash
py auditor.py
# or: python auditor.py
```

### 4. Interactive Auto-Patching
When prompted in the terminal:
```text
⚡ Would you like Apertus Sentinel to automatically generate patched files? (y/n): y
```
Apertus Sentinel will extract secure code patches generated by `Apertus-v1.5-8B` and write them to the `patched_files/` directory.
